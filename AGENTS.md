# Instructions for Coding Agents

Before starting any work in this repository:

1. Read `docs/SESSION_HANDOFF.md` first, then `docs/ROADMAP.md`, `docs/ARCHITECTURE.md`, and relevant parts of `docs/SECURITY_MODEL.md`.
2. Inspect `git status`, the current branch, and the latest commits before editing. Never discard user changes or force-push.
3. Make the smallest verifiable change. Run the available tests and clearly distinguish executed checks from assumptions.
4. Never execute student code or third-party course scripts on the host. The current checker is intentionally text-only.
5. Preserve existing learner files. Do not broaden permissions or disable Webview CSP as a shortcut.
6. At the end of every meaningful stage, update `docs/SESSION_HANDOFF.md`, `docs/ROADMAP.md`, and `docs/DECISIONS.md` with verified outcomes, the current commit SHA, known issues, and the next task.
7. Do not claim the marketplace, remote repository, secure runner, CI result, or GUI smoke test exists unless verified from the current repository and execution results.
